# Szablony zgłoszeń (hack.cert.pl)

Gotowe szablony do wypełnienia w formularzach na https://hack.cert.pl/.
Każde zgłoszenie musi zawierać pełny **PoC (Proof of Concept)** i instrukcję odtworzenia krok po kroku.

## Pliki

| Plik | Przeznaczenie |
|------|---------------|
| `report.md` | Uniwersalny szablon zgłoszenia podatności |
| `scope.md` | Zakres (scope) i wyłączenia dla każdego programu |
| `poc-example.md` | Przykład dobrze przygotowanego PoC |

## Zasada złota

> Nie ujawniaj luki publicznie do momentu wdrożenia poprawki przez administratorów (wymagana pełna dyskrecja).

Zgłaszaj wyłącznie przez formularze na hack.cert.pl — nie przez e-mail, nie przez Twitter/DM.
